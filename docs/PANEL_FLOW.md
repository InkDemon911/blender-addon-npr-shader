# 面板操作流程（PANEL FLOW）

对应 N 面板 **三渲二 / NPR** 标签页。所有面板都可折叠，默认只展开「主控」与「材质组」。

```
N 面板
└── 三渲二 / NPR
    ├── ① 主控 / 一键应用
    ├── ② 材质组            （UIList）
    ├── ③ 组内容（加入 / 移除）
    ├── ④ 组设置
    │   ├── 部位与贴图
    │   ├── 明暗与阴影
    │   ├── 高光
    │   ├── 边缘光
    │   ├── 描边
    │   └── 高级
    └── ⑤ 高级 / 工具
```

---

## 流程 A：给一个角色套上 NPR（最常用）

```
选中网格 → ② 材质组里点「身体」→ ① 一键应用
```

1. **选中物体**：在 3D 视图选中一个或多个网格。
2. **选组**：② 面板的列表里点一下目标组（高亮即选中）。
3. **选模式**：① 面板的「应用模式」默认是 **替换并保留贴图**。
   想保留原材质对照就选 **追加**；只想加描边就选 **仅描边**。
4. **点「一键应用」**：
   - 生成 / 复用 NPR 材质并挂到材质槽
   - 按组设置写入主组参数
   - 按「自动识别贴图」开关决定是否从原材质接管贴图
   - 若勾了「同时生成描边」则一起生成描边外壳
5. **撤销**：任何一步都可以 `Ctrl+Z`；面板上的「撤销上一次应用」按钮等价。

> 结果会写进 `Info` 编辑器，例如
> `已把 1 个材质槽替换/追加为 NPR_身体_Body`。

## 流程 B：管理材质组

| 操作 | 位置 | 说明 |
|---|---|---|
| 新建组 | ② → 新建组 | 弹窗输入名称 + 选部位 + 选预设模板（可 NONE） |
| 重命名 | ② → 重命名 | 弹窗；材质元数据里的组名会同步 |
| 复制 | ② → 复制 | 连贴图槽与参数一起复制 |
| 排序 | ② → ▲ / ▼ | 只影响列表顺序，便于归类 |
| 删除 | ② → 删除 | 弹窗确认；不会删除已生成的材质 |
| 加材质进组 | ③ → 加入选中物体的材质 | 把选中物体当前材质登记进本组 |
| 移出 | ③ → 从本组移除 | 只解除登记关系 |
| 清空 | ③ → 清空本组材质 | 清空登记列表（保留组本身） |
| 选中组内物体 | ③ → 选中本组物体 | 按登记关系选中场景里对应物体 |
| 应用整组 | ④ → 应用到选中物体 | 用当前组参数重刷所有登记材质 |
| 从材质反读 | ④ → 从材质反读参数 | 读取选中物体 NPR 材质的实际参数回填到组 |
| 重置 | ④ → 重置为参考默认 | 组参数回到参考文件实测值 |

## 流程 C：调出想要的颜色 / 明暗

```
④ 组设置 → 部位与贴图
   基础色 / 色调    ← 设成彩色即整体染色（白色 = 不改动贴图）
   基础色亮度       ← 1.0 = 中性；参考文件的压暗值是 0.2
   花纹强度         ← 衣服常用 8.0
   Ramp 强度 + 启用阴影 Ramp  ← 有 Shadow_Ramp 贴图时才打开
```

**没有贴图时**：把「基础色 / 色调」设成想要的颜色即可，因为贴图链会输出白色占位，
乘上色调就是纯色本身。

**有贴图时**：色调会乘在贴图上。想完全还原参考文件外观，请把
`*_Diffuse` / `*_Lightmap` / `*_Normalmap` / `*_Shadow_Ramp` / `MetalMap`
分别接进对应槽位，并把「基础色亮度」调回 0.2。

> **重要**：高光与阴影层次由**光照贴图**驱动。不提供光照贴图时，
> 插件会把高光贡献压到 0 —— 画面是"平"的纯色，而不是错误地顶白。

## 流程 D：加描边

```
④ 组设置 → 描边
   启用描边 ✓
   模式：独立外壳 / 修改器
   厚度：0.01 ~ 0.03（按模型尺度调）
   颜色：通常近黑
```

- **独立外壳**（推荐）：生成独立对象 `NPR_Outline_<组>_<源对象>`，
  用 Solidify（`offset = 1.0`）+ 翻转法线 + 背面剔除 + 纯色材质。
  重复执行**不会**重复创建，只更新参数。
- **修改器模式**：直接给原对象加 Solidify 修改器，不产生新对象。
  适合薄片 / 非流形网格。

只想加描边、不动材质时，用流程 A 的第 3 步选 **仅描边** 模式。

## 流程 E：复用与排查

- **重建节点组**（⑤ 面板）：改动过节点组，或换 Blender 版本后界面异常时点一下，
  会按当前版本重新构建 18 个节点组。
- **自检**（⑤ 面板）：检查节点组是否齐全、连线是否有效、参数名是否都能绑上主组接口。
- **渲染设置**（⑤ 面板）：一键把 EEVEE 的 `View Transform` 设为 `Standard`。
  参考文件是按 Standard 调的；用 AgX/Filmic 会把颜色冲淡。
- **清理**（⑤ 面板）：移除插件生成的材质与描边对象（带插件标记的才会被删）。
