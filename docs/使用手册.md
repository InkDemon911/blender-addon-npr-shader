## 1. 安装与启用

插件已安装在：

```
C:\Users\ink\AppData\Roaming\Blender Foundation\Blender\5.2\scripts\addons\npr_studio
```

并且**已在偏好里启用**，打开 Blender 即自动加载。

如果换机器或重新安装：

1. 把 `npr_studio` 文件夹复制到上面那个 `addons` 目录；
2. `编辑 → 偏好设置 → 插件`，搜索 **NPR**，勾选 **NPR Studio**；
3. 3D 视图按 `N`，侧栏出现 **三渲二 / NPR** 标签页。

> **节点组会自动补齐。** 不管你什么时候启用插件，只要点任意一个 NPR 按钮，
> 插件都会先检查并补建 18 个 Shader 节点组。看到面板却暂时没有节点组时，
> 随便点一下按钮即可。

## 2. 三分钟上手

```
① 按 N 打开侧栏 → 找到「三渲二 / NPR」
② 展开「材质组管理」→ 点「创建预设组」        ← 一次性，之后一直有
③ 选中你的角色网格（可框选多个）
④ 展开「材质组管理」→ 点一下「身体」组
⑤ 展开「一键应用」→ 点「一键应用三渲二」
```

就这样。默认模式是 **替换并保留贴图**，它会自动把原材质里的贴图按用途认出来接进去。

出来的效果如果是"平的纯色"，属于正常 —— 见 [第 7 节](#7-调参从平到立体)。

## 4. 核心概念：材质组

一个**材质组** = 一批材质 + 一套共享的着色/描边参数。

为什么要这样设计：参考文件里 39 个材质共用同一个 `Shader` 节点组，只是**部位不同**。
所以插件也按"组"管理：同一个组里的所有材质用同一套参数，靠**部位**（脸/身体/头发/…）
决定用哪张贴图。

### 8 个预设组

| 组名 | 部位 | 用途 |
|---|---|---|
| 衣服 | Body01 | 服装本体（花纹强度默认调高） |
| 头发 | Hair | 头发（高光锐度偏高） |
| 身体 | Body | 皮肤 |
| 眼睛 | Eyes | 眼球（含瞳孔 A/B/C 槽） |
| 脸部 | Face | 面部（配 SDF 贴图） |
| 睫眉 | Face | 睫毛/眉毛 |
| 口齿 | Face | 口腔/牙齿 |
| 金属 | Body01 | 金属件（金属度调高） |

### 组的基本操作

| 想做什么 | 怎么做 |
|---|---|
| 新建自己的组 | 「材质组管理」→ 新建组 → 填名字、选部位、选模板 |
| 改名字 | 选中组 → 「组名」字段直接改 |
| 改部位 | 选中组 → 「部位」下拉框 |
| 复制一个组 | 复制按钮（连材质列表一起复制） |
| 调整顺序 | ▲ / ▼ |
| 删除 | 删除按钮（**不会**删掉已生成的材质） |
| 让某组不参与批量 | 取消勾选「启用」 |

## 5. 一键应用：四种模式

在「一键应用」面板里选模式，然后点按钮。

| 模式 | 做什么 | 什么时候用 |
|---|---|---|
| **替换并保留贴图**（默认） | 换成 NPR 材质，并把原材质里的贴图按用途识别后接进去 | 绝大多数情况 |
| 替换 | 换成 NPR 材质，不接任何贴图 | 想要纯色、自己后续接图 |
| 追加 | **新增**材质槽，原材质保留 | 想对比原版 / 随时切回 |
| 仅描边 | 完全不动材质，只生成描边外壳 | 已经有 NPR 材质，只缺描边 |

**材质槽策略**：

- `全部槽位` —— 每个材质槽都换成 NPR（默认）
- `仅活动槽` —— 只换当前高亮的那一个
- `仅第一个槽` —— 只换第 0 个

**两个开关**：

- `自动识别贴图` —— 从原材质里按文件名/色彩空间认贴图（`*_Diffuse`、`*_Lightmap`…）
- `同时生成描边` —— 应用材质后顺手生成描边

> 所有操作都能 `Ctrl+Z` 撤销。

## 6. 材质分配（勾选式）

这是"**我要把选中物体上的哪几个材质放进这个组**"的地方。

### 完整流程

```
① 「材质组管理」里点一下目标组（比如「身体」）
② 在 3D 视图选中带材质的物体
③ 「材质分配」→ 点「收集选中物体的材质」
      → 候选材质列表出现，每条前面有勾选框，右侧显示来源（如 Body[0]）
④ 勾选你想加入的材质（默认全勾）
      已经在该组里的会显示「已在组内」，不会重复加
⑤ 点「把勾选的 N 个材质加入当前组」
```

### 面板上的每个按钮

| 按钮 | 作用 |
|---|---|
| **收集选中物体的材质** | 把选中物体所有材质槽里的材质收进候选列表（按材质去重） |
| **收集场景全部** | 把 `bpy.data.materials` 里所有材质收进候选（想手动挑时用） |
| **全选 / 全不选** | 批量勾选 |
| 🗑（收集行右侧） | 清空候选列表（**不动**组内材质） |
| **+**（候选列表右侧） | 只把当前高亮的那一条加入组 |
| ⟳（候选列表右侧） | 重新收集（保留原有勾选状态） |
| **把勾选的 N 个材质加入当前组** | 正式加入 |
| **或：把选中物体全部材质加入组** | 快捷方式，跳过勾选 |

### 组内材质列表

- 显示**材质名**（如果给候选起过备注名，会额外显示在括号里）
- 若材质 `users == 0`（没有用户），会标注「0 用户」提示你可能是个孤立的材质
- `−` 移除高亮的那条；🗑 清空整个列表
- **选中本组物体**：按组内材质反查并选中场景里用到它们的物体
- **同步部位**：把组参数重新写进组内所有材质

### 为什么是"勾选"而不是"用材质编辑器里选中的材质"

Blender 5.2 已经把 `Material.select` 属性移除了，插件**无法**询问
"材质编辑器里当前选中了哪些材质"。所以插件自己维护一份候选列表 + 勾选状态，
选择权明确交给你，还能跨物体合并去重。

## 7. 调参：从平到立体

**先说结论：默认参数下画面会是"平的纯色"，这是设计取舍，不是 bug。**

原因：参考文件的高光与阴影层次**完全由光照贴图驱动**。插件在你不提供贴图时，
会让高光贡献归零 —— 宁可平，也不要错误地顶成一片白。

### 想要立体感，按优先级做

**第一步：给个颜色**
「组设置 → 部位与贴图」→ **基础色 / 色调** 设成你想要的颜色。
没有基础色贴图时，这里就是最终颜色。

**第二步：接光照贴图（最关键）**
把 `*_Lightmap` 贴图接到「阴影 / 光照贴图」槽。这一张图决定：
- R 通道 → 高光分支阈值
- G 通道 → AO / 阴影
- B 通道 → 金属切换
- A 通道 → Ramp 条数遮罩

**第三步：接 Ramp 贴图**
「阴影 Ramp 贴图」接上 `*_Shadow_Ramp`，然后把「启用阴影 Ramp」打开，
「Ramp 强度」调到 0.65 附近。**没接图时千万不要打开** —— Ramp 结果是白色，
乘上去会整体提亮。

**第四步：接金属贴图**
`MetalMap` 接到「金属 / 高光蒙版」，高光才会真的出现。

**第五步：打开边缘光**
「组设置 → 边缘光」→ 勾「启用边缘光」，调「强度」和「锐度」。

### 关键参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| 基础色 / 色调 | 白 | 白=不改动贴图；彩色=整体染色；无贴图时=最终颜色 |
| 基础色亮度 | **1.0** | 整体明暗。参考文件用 0.2（因为它始终有贴图）。想复刻参考外观就调 0.2 |
| 基础色增益 + 增益强度 | 1.0 / **0** | 增益强度=0 时不生效；=1 时完整乘上「增益色增益」 |
| 花纹强度 | 0 | 花纹叠加（Detail 1–4）的整体强度，衣服常用 **8.0** |
| Ramp 强度 + 启用阴影 Ramp | 0.65 / **关** | 没接 Ramp 图时保持关闭 |
| AO 平滑上下限 | 0.2 / 0.3 | 参考文件实测值 |
| 高光锐度 | 5.0 | Blinn-Phong 指数 |
| 高光阈值 / 金属阈值 | 0.7 / 0.55 | 参考文件实测值 |
| 边缘光 强度/锐度/松弛度 | 1.0 / 4.8 / 0.2 | |

## 8. 贴图怎么接

「组设置 → 部位与贴图」里有 8 个贴图槽。点槽位选择图像，或把图像从
大纲视图拖进去。

| 槽位 | 接哪张图 | 色彩空间 |
|---|---|---|
| 基础色贴图 | `*_Tex_{部位}_Diffuse.png` | sRGB |
| 阴影 / 光照贴图 | `*_Tex_{部位}_Lightmap.png` | Non-Color |
| 法线贴图 | `*_Tex_{部位}_Normalmap.png` | Non-Color |
| 阴影 Ramp 贴图 | `*_Shadow_Ramp.png`（256×20） | sRGB |
| 金属 / 高光蒙版 | `MetalMap.png` | Non-Color |
| 面部 SDF 贴图 | `FaceLightmap.png` | sRGB |
| 自发光贴图 | 自发光 | sRGB |
| Alpha 贴图 | 透明度 | Non-Color |

**自动识别**：一键应用时勾了「自动识别贴图」，插件会按文件名关键词
（`Diffuse` / `Lightmap` / `Normalmap` / `Shadow_Ramp` / `MetalMap` / `FaceLightmap`）
和色彩空间自动归类；认不出的就留空，**不猜**。

**清空某个槽**：槽位右边的 `✕` 按钮。只清引用，不删图像数据块。

## 9. 描边

「组设置 → 描边」：

- **启用描边** —— 总开关
- **模式**：
  - `独立外壳`（推荐）—— 生成独立对象 `NPR_Outline_<组>_<源对象>`，
    实现是 **Solidify（offset=1.0）+ 翻转法线 + 背面剔除 + 纯色材质**
  - `修改器模式` —— 直接给原对象加 Solidify，不产生新对象；适合薄片/非流形网格
- **厚度** —— 按模型尺度调，一般 0.01 ~ 0.03
- **颜色** —— 描边颜色，通常近黑（不是纯黑，纯黑在暗部会显脏）

**重复执行不会重复创建**，只会更新参数。

薄片物体（如裙摆平面）用独立外壳可能出现穿插，改用修改器模式。

## 10. 颜色不对怎么排查

按这个顺序查，90% 的问题在前两步：

**① 先确认渲染设置**
「材质与渲染」→ 点「设为 Standard」。用 AgX / Filmic 会把三渲二的纯色冲淡。

**② 确认基础色亮度不是 0.2 而你没贴图**
没贴图时贴图链输出白色占位，0.2 会把画面压成近黑。把「基础色亮度」设回 1.0。

**③ 确认高光没被顶白**
如果画面是纯白而不是纯色：说明高光分支在加白。检查是否接了光照贴图 ——
参考文件的高光依赖它。没有贴图时插件会把高光贡献归零，理论上不该白；
如果还白，把「启用高光」关掉验证一下。

**④ 确认节点组健康**
「高级 / 工具」→ 点「自检」。它会检查 18 个节点组是否齐全、连线是否有效。

**⑤ 看日志**
「高级 / 工具」里能看到最近 200 条操作日志（INFO / WARN / ERROR 分级）。

## 11. 快捷键与效率技巧

| 技巧 | 说明 |

## 12. 常见报错与解决

| 报错 | 原因 | 解决 |
|---|---|---|
| 「没有选中的材质组」 | 没在组列表里点选组 | 先在「材质组管理」里点一下目标组 |
| 「候选列表为空」 | 还没收集 | 点「收集选中物体的材质」 |
| 「选中的 N 个材质都已经在组里了」 | 重复添加 | 正常提示，换别的材质或先移除 |
| 「无效的贴图槽：xxx」 | 传了不存在的槽名 | 从面板上的 `✕` 按钮点，不要手写槽名 |
| 「选中的物体上没有材质槽」 | 物体没有材质 | 先给物体加材质，或用「追加」模式 |
| 侧栏没有 NPR 标签页 | 插件没启用 / 注册失败 | 偏好设置里勾选；仍不出现就看 [第 13 节](#13-卸载与还原) |
| 面板有但按钮点了没反应 | 节点组缺失 | 点任意 NPR 按钮会自动补齐；或「高级 / 工具 → 重建节点组」 |

## 13. 卸载与还原

**只是不想用了**：偏好设置里取消勾选 **NPR Studio**。

**想清理场景里生成的东西**：
「高级 / 工具」里有清理入口，只删除带插件标记的材质与描边对象
（`NPR_*` 材质、`NPR_Outline_*` 对象），**不会**动你自己的材质。

**想彻底删掉**：取消勾选后，删掉
`...\5.2\scripts\addons\npr_studio` 文件夹即可。

**用「追加」模式套的材质**：直接删掉对应的材质槽就能回到原样。
