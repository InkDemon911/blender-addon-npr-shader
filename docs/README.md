# NPR Shader — Blender 5.2 / EEVEE 三渲二（NPR）插件

一个**完全自包含**的三渲二着色插件：所有节点组都由 Python 在插件内构建，
不依赖任何外部 `.blend` 文件或用户已安装的节点组资产。
拓扑、接口、固定数值严格对照参考文件 `OdetteV3.blend`（见
`docs/REFERENCE_MAPPING.md` 的变量对照表）。

## 1.1 安装相关的三个坑（已在代码里修掉）

1. **启动期 `bpy.data` 是受限代理**
   在 Blender 启动阶段启用插件时，`bpy.data.node_groups` 会抛
   `AttributeError: '_RestrictData' object has no attribute 'node_groups'`。
   若直接在 `register()` 里构建，注册会失败，插件停留在
   "偏好里勾了但没加载"的状态（面板不出现）。
   → 现在改为"先试一次，失败就挂 `load_post` + timer 兜底"。

2. **`ensure_all()` 只看名字会让空组永久残留**
   如果某个名字下已有一个**空节点组**，按名字判断会认为"已存在"而永远跳过重建，
   材质里挂上的就是没有接口的空组 —— 表现为插件"装了但没效果"。
   → 新增 `_tree_is_healthy()`：检查"有节点、有 Group Output、接口里有输出插槽"，
   不健康就重建。

3. **操作符 `execute` 必须恰好 2 个参数**
   给基类 `execute` 包自愈逻辑时，若用"带默认值的第三参数"捕获原方法，Blender 会抛
   `ValueError: expected Operator ... class "execute" function to have 2 args, found 3`，
   整个注册随之失败。
   → 改用闭包捕获，签名保持 `execute(self, context)`。

自愈逻辑挂在操作符基类上（`NprOperator.__init_subclass__` 自动包装每个子类的
`execute`），所以**每个入口都会先补齐节点组**，不依赖 Blender 的回调时机。

## 2. 快速上手（3 步）

1. **选物体**：选中角色网格（可多选）。
2. **选组**：在 N 面板 → **材质组** 里点一个预设组
   （衣服 / 头发 / 身体 / 眼睛 / 皮肤 / 金属 / 水晶 / 特效）。
3. **点应用**：按 **一键应用**（默认「替换并保留贴图」模式）。

描边默认跟随组设置一起生成；也可以只按 **仅生成描边** 单独加描边。

## 3. N 面板结构

| 面板 | 作用 |
|---|---|
| **主控 / 一键应用** | 应用模式（替换 / 追加 / 仅描边 / 替换并保留贴图）、材质槽策略、是否自动识别贴图、是否同时生成描边；一键应用 / 撤销 |
| **材质组** | 组的列表（UIList）：新建 / 重命名 / 删除 / 复制 / 上下排序；显示每组部位与材质数 |
| **组内容（加入 / 移除）** | 把选中物体的材质加入当前组、从组里移除、清空组、选中组内物体 |
| **组设置** | 部位（脸/身体01/身体/头发/眼睛/水晶）、贴图输入、明暗与阴影、高光、边缘光、描边、高级参数；应用整组 / 从材质反读 / 重置为参考默认 |
| **高级 / 工具** | 重建节点组、自检节点组与连线、渲染设置（EEVEE + Standard 色彩管理）、诊断信息 |

## 4. 四种应用模式

| 模式 | 行为 | 适用场景 |
|---|---|---|
| **替换（REPLACE）** | 把每个材质槽的材质换成 NPR 材质 | 标准流程，最干净 |
| **追加（APPEND）** | 新增材质槽，保留原材质 | 想保留原材质做对照/切换 |
| **仅描边（OUTLINE_ONLY）** | 不改材质，只生成描边外壳 | 已有 NPR 材质，只想加描边 |
| **替换并保留贴图（REPLACE_KEEP_TEXTURES）** | 换 NPR 材质，并把原材质里的贴图按用途识别后接进去 | **推荐默认**，最接近原外观 |

材质槽策略可选：**全部槽位（ALL_SLOTS）** / **仅活动槽（ACTIVE_SLOT）** /
**仅第一个槽（FIRST_SLOT）**。

所有操作都通过 `bpy.ops` 的 `undo` 机制登记，可 `Ctrl+Z` 撤销；
生成物（材质、描边对象）都带插件标记，卸载时可选择清理。

## 5. 材质组工作流

- **预设组**：首次启用自动创建 8 个预设（衣服 / 头发 / 身体 / 眼睛 / 皮肤 / 金属 / 水晶 / 特效），
  每个预设都带好部位、贴图槽命名与推荐参数。
- **自定义组**：`新建` → 起名 → 选部位 → 在组设置里调参数 → `应用到选中物体`。
- **把已有材质收进组**：选中物体 → `把选中材质的物体加入本组`。
  组会记录材质与部位，之后可整组重应用。
- **从材质反读**：选中挂了 NPR 材质的物体 → `从材质反读参数`，
  会把材质里主组的实际取值读回组设置（便于把调好的材质固化成组）。
- **重置**：`重置为参考默认` 把组参数恢复成参考文件实测值。

组数据保存在 `.blend` 的场景属性里，随文件走；也可以另存为预设（见 `presets.py`）。

## 6. 参数文档

### 部位（part）
决定材质的 mask 走哪一支：`Face` / `Body01` / `Body` / `Hair` / `Eyes` / `Crystal`。
**同一时刻只有一个部位为 1**，其余为 0 —— 这与参考文件的做法完全一致
（参考文件的 39 个材质实例也全部是默认 mask，靠节点组内部选择贴图）。

### 基础色
| 参数 | 说明 |
|---|---|
| 基础色 / 色调 | 乘到基础色贴图上的色调。**白色 = 不改动贴图**；设成彩色 = 整体染色。没有贴图时这里就是最终基础色 |
| 基础色亮度 | 整体明暗。**1.0 = 中性**；参考文件里贴图链默认用 0.2（因为参考文件始终有贴图）。想复刻参考文件的压暗效果就调到 0.2 |
| 基础色增益 + 增益强度 | 增益强度 = 0 时不生效（乘 1）；= 1 时完整乘上「基础色增益」 |
| 花纹强度 | `Detail 1..4` 四个叠加槽的整体强度（衣服常用 8.0） |
| Ramp 强度 + 启用阴影 Ramp | 未提供 Shadow_Ramp 贴图时 Ramp 结果是白、乘上去会整体提亮，**默认关闭**；有贴图时打开并调 0.65 附近 |

### 明暗与阴影
`AO 偏移`、`AO 平滑上下限`（参考值 0.2 / 0.3）、`AO 加值`、`阴影阈值`。

### 高光
`启用高光`、`高光锐度`（参考值 5.0）、`高光压暗`（1.04）、`高光阈值`（0.7）、
`启用金属`、`金属阈值`（0.55）、`水晶高光阈值`（0.2）。

> **注意**：高光分支在参考文件里由**光照贴图**（LmR/LmB）+ 金属贴图驱动。
> 插件在两张图都没提供时会把高光贡献压到 0，避免退化成"整片顶白"。

### 边缘光（Rim）
`启用边缘光`、`边缘光颜色`、`强度`（1.0）、`锐度`（4.8）、`松弛度`（0.2）、
`上下限`（0.423 / 0.45）。

### 描边
`启用描边`、`模式`（独立外壳 / 修改器）、`厚度`、`颜色`、`材质名`。
实现方式为**倒角外壳**：Solidify（`offset = 1.0`）+ 翻转法线 + 背面剔除 +
纯色描边材质，生成独立对象 `NPR_Outline_<组>_<源对象>`。

### 高级
`Light Euler`（参考值 `-0.34177, 0.67079, -140.36`）、`光强`、
`光环亮度`（Halo Brightness）、`自发光强度`、`SDF 开关`、`Alpha 开关`。

## 7. 兼容性与已知限制

**环境**：Blender **5.2.0 LTS**（hash `fbe6228777e7`）/ EEVEE。
引擎枚举在 5.x 里只有 `BLENDER_EEVEE`，插件会自动适配。

**有意偏离参考文件之处**（都在代码注释里写明原因）：

1. **Rim 用 LayerWeight 数学式实现**，而不是参考文件的
   `MixShader + ShaderToRGB`。因为 `ShaderToRGB` 在 EEVEE Next（4.2+）下对真实
   着色器输入返回黑色，会把整条链打成黑色。
2. **基础色的自发光叠加改为「颜色 × 强度」**，同样是为了绕开 `ShaderToRGB`。
3. **`NPR_BaseColor` 的两个同名 `Result` 输出改名为 `Color` / `Alpha`**。
   参考文件里两个输出都叫 `Result`，同名会让按名称连线必然歧义；
   接口 identifier 仍是 `Socket_0` / `Socket_1`，顺序与参考文件一致。
4. **参考文件里硬编码的常量与内嵌贴图，一律提升为组接口参数**，
   默认值等于参考文件实测值。因此主组的接口数量多于参考文件
   （参考文件只有 `Emission` + 6 个 mask 输入）。
5. **颜色乘算用「拆通道 → Math → 合并」实现，不用 `Mix(MULTIPLY)`**。
   实测 `Mix(blend_type='MULTIPLY')` 在节点组内于
   `A=白 / B=目标色 / Factor=1` 时会输出**两倍**目标色（红 0.1 → 0.1981），
   同一配置放在材质里却正常 —— 行为随上下文变化，不可依赖。

**已知限制**：

- 高光与阴影层次完全依赖光照贴图；不提供贴图时画面是"平"的纯色（这是设计取舍：
  宁可平也不要错误的白）。要还原参考文件的外观，请把 `*_Lightmap` 与
  `*_Shadow_Ramp` 贴图接进对应的组参数。
- 描边是几何外壳方案，对**非流形 / 薄片**网格可能出现穿插或断裂；
  薄片物体建议改用「修改器模式」并视情况调整厚度。
- 未做多语言之外的主题适配；面板使用 Blender 默认色彩。
