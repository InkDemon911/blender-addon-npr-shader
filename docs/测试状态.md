# 测试状态与未验证项（TESTING STATUS）

> **当前版本处于「测试中（testing / beta）」阶段。**
> 本文件诚实列出**哪些已经验证过、哪些还没有**，请在使用前读一遍。

---

## 一句话结论

**着色核心（节点组构建 + 颜色数值）已经过自动化验证；但 GUI 交互、真实生产模型、
跨平台与跨版本全部未经测试。** 请把它当作可用的测试版，而不是稳定版。

## ❌ 未验证（重要）

### 一、GUI 交互（完全未测试）

**所有测试都在 `--background` 无界面模式下跑。** 以下都没有在带界面的 Blender 里
实际点过：

- 面板的**布局、行宽、图标、折叠状态**是否正常
- UIList 的**鼠标点选**、滚动、`▲▼` 排序按钮
- 弹窗式 Operator（新建组 / 重命名 / 删除确认）的**实际交互**
- 滑块拖动时视口**是否实时更新**
- 颜色选择器、文件/图像选择器能否正常弹出
- 多显示器 / 高 DPI 下的显示

> 面板代码按 Blender 5.2 的 `Panel`/`UIList`/`Operator.invoke` 规范编写，
> `register()` 无报错、类都成功登记，但**"能注册"不等于"长得对、点得动"**。

### 二、着色外观（只验证了数值，没验证"好不好看"）

- **没有用真实生产模型跑过**。全部测试都是在一个 1.4 单位的立方体上做的。
- **没有用参考文件里那 28 张 packed 贴图测过**。测试用的是合成贴图与纯色。
- **8 个贴图槽里有 5 个没有端到端验证**（法线 / Ramp / 金属 / SDF / 自发光）。
  目前只验证了基础色链路的颜色数值。
- **Rim 边缘光、高光、SDF 面部**都没有做过外观比对，只有"不报错"。
- **与参考文件的外观一致性没有做过并排比对**。数学式等价是推导的，不是像素级
  比对出来的。
- 已知会偏离参考外观的项（见 README「与参考实现的有意差异」），实际观感差异
  未量化。

### 三、验证顺序的影响（测试步骤互相干扰）

- 测试之间**共用同一个场景状态**，顺序执行。单独执行某一步的行为**没有验证过**。
- 反复"应用 → 撤销 → 再应用"的**幂等性**没有系统测过。
- 在已有 NPR 材质上**再次一键应用**的行为只做了有限验证。

### 四、导入资产与真实管线

- 只测过 Blender 原生立方体。**MMD / FBX / glTF / VRM 导入的模型完全没测**。
- 多 UV 图（参考文件有 `UVMap` / `UV1` / `UV2` 三套）**没有验证**，插件目前只用
  默认 UV。
- 多物体、多材质槽、共享材质（多物体引用同一材质）**没有测过**。
- 材质库（`bpy.data.materials` 里成百上千个材质）下的**性能没测**。

### 五、描边的几何健壮性

- 薄片 / 非流形 / 带修改器的网格**可能出现穿插或断裂**，未系统测试。
- 动画变形（骨骼 / 形态键）下描边外壳**是否会穿帮未验证**。
- 描边厚度与模型尺度的**合理范围未标定**（不同大小模型需要不同厚度）。

### 六、平台与版本

- **只在 Windows 上测过**。macOS / Linux 完全未测。
- **只在 Blender 5.2.0 LTS 上测过**。5.0 / 5.1 / 4.x **未测**，`bl_info` 里声明的是
  `(5, 2, 0)`。
- 显示缩放（125% / 150% DPI）下的 UI 未测。
- Blender 的**多语言界面**（英文界面下中文面板名混排）未测。

### 七、数据与持久化

- `.blend` **保存后重新打开**，材质组 / 候选列表 / 日志是否正确恢复——**未验证**。
- 场景链接（Link/Append 到别的 .blend）后的行为未测。
- 多人协作（同一 `.blend` 被不同 Blender 版本打开）未测。

### 八、卸载与清理

- 卸载插件后场景里残留的数据块清理**只做了基本验证**。
- 「清理生成物」功能**没有在复杂场景里测过**。

---

## ⚠️ 已知限制（不是 bug，是设计取舍）

1. **高光与阴影层次完全依赖光照贴图**。不提供 `*_Lightmap` / `*_Shadow_Ramp` 时
   画面是"平"的纯色 —— 宁可平，也不要错误地顶成一片白。
2. **描边是几何外壳方案**，对非流形 / 薄片网格可能穿插，建议改用修改器模式。
3. `base_brightness` 默认 `1.0`，而参考文件是 `0.2`（那是"已有贴图时的压暗系数"）。

请带上这些信息提 [Issue](https://github.com/InkDemon911/blender-addon-npr-shader/issues)：

- Blender 版本（`帮助 → 关于 Blender`）
- 操作系统
- 「高级 / 工具」面板里的**日志**（最近 200 条）
- 复现步骤
- 如果有报错，贴控制台输出（`窗口 → 切换系统控制台`）

**在测试阶段，报错信息比什么都值钱** —— 哪怕是"这个按钮点了没反应"这种。
